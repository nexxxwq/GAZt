# GAZt — Интеллектуальная система обнаружения утечек газа

Проект по обнаружению и локализации утечек газа на объектах Единой системы газоснабжения с помощью нейросетевого анализа данных АСУ ТП.

## Описание

В проекте исследуется задача локализации утечки газа в трубопроводе.
Подход основан на сочетании:

- физической модели течения газа (уравнение Дарси–Вейсбаха),
- генерации синтетического датасета (12 000 наблюдений),
- модели машинного обучения (нейросеть LeakNet).

## Цель

Определить координату утечки вдоль трубопровода на основе измеряемых параметров:

- давления на входе и выходе,
- расхода газа на входе и выходе,
- геометрических параметров трубы,
- физических характеристик газа.

## Стейкхолдеры

- ПАО «Газпром» — владелец Единой системы газоснабжения.
- ПАО «НОВАТЭК» — крупнейший независимый производитель газа.
